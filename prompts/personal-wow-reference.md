# Personal WoW reference: a prompt

Guide sites are thorough but general. This prompt has an AI assistant with web search
build a reference for your own characters: which professions they have, what each one
feeds, and what to do next. Regenerate it each patch instead of maintaining it.

## The prompt

> Build me a single-page reference for World of Warcraft, current retail patch [PATCH].
>
> My characters: [NAME, CLASS/SPEC, PROFESSIONS, LEVEL] for each.
> My goal: [gold first, gearing second / leveling / Mythic+ / etc.].
>
> For each profession: the specialization trees, the order to spend knowledge points for
> my goal, what to skip early, where the gold is, and where to buy knowledge points (vendor,
> town, renown, cost). Note which of my characters supply mats to which.
>
> For a class: spec choice for my goal, rotation, talents by level, utility, and anything a
> returning player from [EXPANSION] would have missed.
>
> Rules: use current-patch sources (Icy Veins, Wowhead, Method, Maxroll, Petopia) and do
> not substitute older expansion information. Give a confidence level for each section,
> cite source URLs, use town names rather than coordinates, and say "unknown" rather than
> guess. End with a short list of things to check in game.

## Tips

- Correct it as you play. Spelling of character names, things you confirmed in game.
- Keep each class or profession set on its own page.
- Ask for a refresh when the patch changes.
